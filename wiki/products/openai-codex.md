## Summary

OpenAI Codex, originally an API and coding-agent surface, has been repositioned in April 2026 as a unified ChatGPT + Atlas + Codex app that multiple newsletters described as OpenAI's clearest "superapp" move yet. The update folds background computer use, parallel agents, an in-app browser, and image generation into one product, and expands Codex beyond code into broader knowledge tasks across the ChatGPT desktop app, CLI, and IDEs. Rate limits were doubled alongside the repositioning. Together with the related OpenAI Agents SDK update (native harness for cross-file / tool workflows, sandboxed execution), this positions Codex as [[openai]]'s primary long-running agent surface, counterpart to [[claude-code]] at [[anthropic]].
