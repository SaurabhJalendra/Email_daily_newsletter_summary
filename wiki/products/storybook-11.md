## Summary

Storybook 11 is the November 2026 beta release of the Storybook UI component-development workbench. The release introduces *"official skills and headless CLI tools that let agents iterate autonomously in a smaller package with faster context delivery"* — productizing Storybook as a canonical agent-friendly UI dev-tool substrate where AI coding agents (Claude Code, Cursor, Devin, Muse Code, etc.) can autonomously author, test, and iterate on UI components without requiring human interaction with Storybook's browser-based UI. The combination of official skills (connecting to the [[claude-mods]] + Anthropic Skills ecosystem patterns) and headless CLI positions Storybook 11 as a concrete bridge between the UI-component-development surface and the agent-loop automation substrate, aligned with the mid-2026 [[ai-native-sdlc]] + [[software-factories]] substrate cluster.
