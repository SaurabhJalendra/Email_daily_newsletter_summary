## Summary

Antigravity 2.0 is Google's rebuilt-from-scratch successor to the 2025-11 [[antigravity]] IDE — a standalone desktop app + CLI + SDK announced at Google I/O 2026 (2026-05-19) and powered by [[gemini-3-5-flash]]. Unlike v1 which was a VS Code fork, v2 is a separately-built agentic-development surface designed to orchestrate multiple AI agents working on the same project simultaneously, with native support for parallel sub-agents, scheduled background tasks, voice commands, and integration with Android, Google Workspace, and the web. Includes a Go-built terminal (Antigravity CLI) replacing the deprecated Gemini CLI, and an SDK supporting Bash/Python/Node/custom markdown-defined skills. Internal demos: built a functional operating-system framework from scratch in 12 hours. Pairs with [[gemini-3-5-flash]] (4× faster than rivals) as the engine and [[gemini-spark]] (24/7 personal agent) and [[gemini-omni]] (any-input → video) as the I/O 2026 trio.
