## Summary

Perplexity Brain is [[perplexity]]'s self-improving memory system for AI agents, launched 2026-06-20. It builds a **persistent context graph** that spans tasks, projects, decisions, files, and sources — enabling agents to **start with relevant context instead of starting from scratch**, and **linking every memory to its original source** for provenance tracking. Brain is positioned alongside Anthropic's Claude file-based memory + OpenAI's ChatGPT Dreaming + GPT-5.4 "Stateful AI" + Google Gemini's per-app context as a Q2-2026 cross-lab convergence on long-running per-user agent memory (see [[ai-memory]]).

The structurally novel signal in Brain vs prior frontier-lab memory surfaces is the explicit **source-linking** primitive: every memory tile retains a back-reference to the original source (file, web page, prior conversation, tool output) — which makes the memory graph auditable and (with Perplexity's broader search-as-code substrate) re-queryable as agents accumulate decisions over time. The "self-improving" framing implies the graph can refine its own structure (consolidate / split / re-link memory nodes) as new evidence arrives, distinguishing Brain from pure append-only memory logs.
