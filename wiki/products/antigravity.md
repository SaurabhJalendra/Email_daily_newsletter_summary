## Summary

Antigravity is [[google]]'s free, "agent-first" coding IDE launched alongside [[gemini-3]] on 2025-11-18. It is forked from VS Code and runs multiple autonomous AI agents with direct access to editor, terminal, and browser. Agents emit "Artifacts" — task lists, screenshots, browser recordings — that document their work, making multi-agent execution auditable. Antigravity is positioned as Google's direct answer to [[cursor]], [[claude-code]], and [[github-agent-hq]] in the agent IDE category.
