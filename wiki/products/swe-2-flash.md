## Summary

SWE-2 Flash is [[cognition]]'s Nov 4 2026 Flash-tier coding model for Devin — designed for frequent, latency-sensitive agentic software-engineering work such as repository navigation, code review, documentation updates, test triage, and small feature changes. It is built on [[thinking-machines]]' **Inkling-Small** sparse-mixture-of-experts model (the 276B-A12B sibling of [[inkling]]), and Cognition reports it is approximately **three times faster** and **one-fifth the price** of SWE-2.

The release marks Cognition's pivot from Chinese-open-weight substrate (SWE-1.7 on [[kimi-k2-7-code]]) to **American-open-weight substrate** (Inkling-Small), and extends Cognition's coding-model line into a specialized Flash-tier alongside the full SWE-2 Pareto-frontier model. SWE-2 Flash ships inside Devin Desktop and CLI rather than as a standalone API. Performance and cost claims are vendor-reported; independent benchmarks are not yet available.
