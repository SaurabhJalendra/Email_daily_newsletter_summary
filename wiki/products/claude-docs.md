## Summary

Claude Docs is Anthropic's September 2026 beta document-authoring product surface, launched as part of the unified-Claude-app collapse that merged Chat + Cowork + Design into one interface. It ships in beta alongside [[claude-slides]] — the twin productization move canonicalizes Anthropic's push into productivity-suite tier substrate competitive with Google Docs and Microsoft Word.

Structurally, Claude Docs extends Anthropic's multi-cycle vertical-productization arc ([[claude-for-excel]] + [[claude-for-legal]] + [[claude-for-word]] + [[claude-for-teachers]] + [[claude-for-small-business]] + [[claude-money]]) into a *native-Anthropic document-authoring substrate* rather than a wrapper on top of Microsoft/Google surfaces. The Evolving AI Insights framing groups Docs + Slides + Design as three surfaces merged into "one interface" — suggests Claude Docs sits alongside [[claude-slides]] and [[claude-design]] under a unified productivity-and-creative suite.
