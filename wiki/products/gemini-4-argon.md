## Summary

Gemini 4 Argon is [[google]]'s Sep 30 2026 flagship [[gemini]]-4-family frontier model, positioned for complex coding, enterprise knowledge work (legal + financial workflows), long-document analysis, and cybersecurity defense. Argon ships with an industry-leading **1 million-token output limit** (up from 64,000 in the prior generation), introductory pricing of **$2/M input + $10/M output** rising to **$4/$20** post-promo, and Google-reported state-of-the-art scores on **DeepSWE v1.1 (77.9%)**, **Vals Index leadership** for economically weighted professional work, a **68% tie for first on CWE-bench v1** (vulnerability remediation), and **91.9% on Vibe Code Bench**. Google says Argon leads on 13 of 18 disclosed benchmarks, though competitors still lead on **FrontierSWE**, **Terminal-Bench**, and some science-focused evaluations ([[openai-astra]] on some SWE + computer-use benchmarks; [[claude-opus-5-5]] on Terminal-Bench + several coding evals). Initial access is restricted to vetted cyber defenders and security firms via Google's **Fairwind Program** + U.S. government pre-release safety evaluation; broader developer, enterprise, and consumer availability has not yet been dated.

Structurally, Argon is Google's first-in-wiki concrete Gemini-4-family variant to ship — reaching partners *before* the broader Gemini 4 release that Koray Kavukcuoglu disclosed as "in post-training" on 09-26-evening. The staged, Fairwind-Program-gated rollout signals Google is adopting a Trusted-Access release pattern for high-capability frontier models, structurally parallel to the mid-2026 [[gpt-5-6-cyber]] + [[mai-cyber-1-flash]] cybersecurity-vertical frontier-model cohort. Argon lands in the middle of a *canonical late-Sep-to-Oct-2026 three-frontier-lab successive-flagship-release inflection cluster* alongside [[claude-opus-5-5]] (Sep 22) + [[claude-sonnet-5-5]] (Sep 29) + OpenAI's [[openai-astra]] (Sep 3) and cancelled [[gpt-6-1-astra]] (Sep 29). Google is also *using Argon internally at scale*: Argon agents have freed up over 300 TiB of Google data-center memory and migrated more than 800K lines of C/C++ kernel code to Rust — the first-in-wiki concrete production-tier dog-fooding datapoint on a frontier-lab-internal-agent-deployment substrate.

## Key Facts

- **Vendor**: [[google]] / Google DeepMind
- **Family**: Gemini 4 (first concrete Gemini-4-family variant to ship)
- **Announced**: 2026-09-30
- **Positioning**: flagship frontier model for complex coding + enterprise knowledge work + legal/financial workflows + long-document analysis + cybersecurity defense
- **Output limit**: 1,000,000 tokens (up from 64,000 in prior-gen; industry-leading)
- **Introductory pricing**: $2/M input + $10/M output (planned increase to $4/$20 post-promo)
- **Benchmarks (Google-reported)**:
  - DeepSWE v1.1 — 77.9% (state-of-the-art, real-world software engineering)
  - Vals Index — leadership (economically weighted professional work)
  - CWE-bench v1 — 68% (tie for first; vulnerability remediation)
  - Vibe Code Bench — 91.9%
  - Leads on 13 of 18 disclosed benchmarks
- **Benchmarks where competitors lead**: FrontierSWE ([[openai-astra]]), Terminal-Bench ([[claude-opus-5-5]]), some computer-use evals ([[openai-astra]]), some science-focused evaluations
- **Access**: Fairwind Program — vetted cyber defenders + security firms + U.S. government pre-release safety eval; broader developer/enterprise/consumer rollout planned but not yet dated
- **Named customer**: Wiz (caught a critical hospital-software flaw)
- **Google-internal deployment**: 300+ TiB data-center memory freed + 800K+ lines of C/C++ kernel code migrated to Rust via Argon agents
- **Independent-reporting notes**: Bloomberg reported internal doubts about Argon's coding capabilities, which Google rejected
