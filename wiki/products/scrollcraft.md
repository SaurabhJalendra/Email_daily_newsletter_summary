## Summary

**Scrollcraft** is a free [[claude-code]] skill from Nate Herk that transforms ordinary landing pages into premium, scroll-driven websites without locking every project into the same visual template. The skill interviews the user about the intended user journey, then works with existing or AI-generated assets to compose scroll-triggered animations, section transitions, and visual choreography.
