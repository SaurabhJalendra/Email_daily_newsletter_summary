## Summary

Google Home MCP is Google's September 2026 early-access Model Context Protocol server for the Google Home / Nest smart-home ecosystem. It exposes Nest cameras, thermostats, and other Google-Home-connected devices to LLM-based agents via the MCP standard, enabling Claude + ChatGPT to control physical smart-home devices as MCP tools. Cross-frontier-lab clients are supported at day-one launch — Anthropic's Claude and OpenAI's ChatGPT both named as clients, reflecting Google's neutral-substrate posture on MCP endpoint deployment.

Structurally, Google Home MCP extends the [[model-context-protocol]] adoption arc from prior substrates (IDE + coding-agent + social-platform via X + operational-database via MongoDB Atlas + consumer-web via ChatGPT WebMCP) into a *smart-home / IoT-tier substrate*. It is the first-in-wiki MCP endpoint that bridges LLM agents to physical-world-actuation substrates on a major platform, and reads structurally as *canonical smart-home vertical MCP-substrate anchor*.
