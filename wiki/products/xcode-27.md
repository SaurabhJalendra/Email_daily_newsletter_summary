## Summary

Xcode 27 is Apple's Sep 2026 release of its flagship developer IDE, adding first-party coding agents that can be powered by any model (a departure from Apple's historically closed developer stack). It also introduces Device Hub for centrally managing all developer devices. Positioned as Apple's answer to [[claude-code]] + [[cursor]] + [[jules]] within the Xcode surface itself, it lands alongside [[ios-27]] and the [[siri-ai]] rollout in the same day.

## Key Facts
- **Coding agents**: powered by any model (BYO model, similar to how [[siri-ai]] can be swapped for [[claude-fable-5-1]] or [[chatgpt]])
- **Device Hub**: unified management for all developer devices
- **Workflow customization**: user-configurable agent behaviors within Xcode
