## Summary

Zero is Vercel Labs' July 2026 experimental programming language that inverts the text-as-source-code assumption that has held since UNIX. Rather than storing programs as characters in files, Zero stores programs as a **graph database** — agents patch nodes atomically rather than editing text, and every mutation preserves the AST integrity that text-based edits lose. Zero compiles down to native binaries under 10 KiB and includes a Rust-style **borrow checker**, positioning it as a low-level systems-programming target rather than a scripting language.

The distinguishing design choices target the agentic-tooling era directly: the compiler produces **structured JSON output with stable error codes**, letting agents read and fix errors deterministically without needing to parse natural-language compiler diagnostics; and a `zero skills` command provides **guidance pinned to the exact compiler version**, so agents can always fetch version-matched instructions rather than relying on stale model training data. Zero is explicitly framed as *"still in its early stages and not yet suitable for production use"* — this is a language-design-thesis release, not a production shipment.

Structurally, Zero sits alongside [[vercel-eve]] (Vercel's file-first agent framework) as two parts of Vercel's larger *"production infrastructure for AI agents"* thesis — eve provides the runtime layer, Zero provides the language-and-compiler layer. Both share a design principle: build the substrate to be *agent-inspectable and agent-mutable* at the primitive layer, rather than layering agent-friendly APIs on top of substrates designed for human developers.
