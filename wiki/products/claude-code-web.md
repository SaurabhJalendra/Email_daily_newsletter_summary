## Summary

Claude Code Web is the browser-based surface for [[anthropic]]'s [[claude-code]] coding agent — a cloud-hosted variant aimed at "cloud-based dev work" where users delegate coding tasks without standing up a local CLI. Announced 2025-10-21, it gives Claude Code parity with Google's [[jules]] (web + CLI) and slots into the same competitive frame as cloud-hosted [[cursor]] sessions and OpenAI's web Codex. Claude Code Web is the natural ancestor of the always-on Routines feature added to Claude Code in April 2026, which moves the same workflow from interactive sessions to triggered automation.
