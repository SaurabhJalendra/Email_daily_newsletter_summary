## Summary

Kimi K3 is [[moonshot-ai]]'s formally released frontier open-weight model — a **2.8-trillion-parameter mixture-of-experts model with ~50B active parameters per query (2.8T-A50B)**, released mid-July 2026 as the largest open model ever released. Architecturally, K3 combines **Kimi Delta Attention (KDA)** — a hybrid linear attention mechanism — with **Attention Residuals** and **LatentMoE**, allowing it to scale over 2× beyond prior Kimi models while preserving performance. It offers a **1-million-token context window** and **native visual understanding**, positioning it for long-horizon coding, complex knowledge work, and agentic reasoning.

On benchmarks, K3 scores **57 on the Artificial Analysis Intelligence Index** — comparable to [[claude-opus-4-8]] and GPT-5.5 but behind [[claude-fable-5]] and [[gpt-5-6]] Sol — with **cost per task of ~$0.94** on GDPval v2 + AA-Briefcase (below both Sol and Opus 4.8). It reportedly reaches **~80% on SWE-Bench Pro** and **0.901 on AECV-Bench** for construction drawings. AINews' canonical framing — *"Opus 4.8-class at Sonnet 5 pricing"* — captures K3's positioning: API pricing at **$3/M input + $15/M output** matches [[claude-sonnet-5]] while approaching Opus-4.8-tier capability, running at roughly one-third the cost of Fable 5.

K3 lands as the wiki's fastest leak-to-release resolution — the pulled Moonshot promo page (~July 15) became a formal release within 48 hours — and cements the *Chinese-open-weight frontier-parity* thesis alongside [[inkling]], extending the [[open-source-models]] arc into the ~3T tier. Open weights are expected July 27. Practical constraints include slow inference speed and recommended deployment on **64+ accelerator supernode configurations**.

- Vendor: [[moonshot-ai]]
- Parameters: **2.8T total / ~50B active per query (2.8T-A50B MoE)** — largest open model ever released
- Architecture: **Kimi Delta Attention (KDA)** hybrid linear attention + **Attention Residuals** + **LatentMoE**
- Context window: **1M tokens**
- Modalities: text + native visual understanding (image); Anna's Daybreak notes video-input support
- Incubation cycle: **~1.5 years, starting January 2025**
- API pricing: **$3/M input + $15/M output** (matches [[claude-sonnet-5]] tier)

- Artificial Analysis Intelligence Index: **57** (~Opus-4.8/GPT-5.5-tier; behind Fable 5 + GPT-5.6 Sol)
- SWE-Bench Pro: **~80%**

- Availability: Kimi API + Kimi app + Kimi web (free chat access with Kimi account)
