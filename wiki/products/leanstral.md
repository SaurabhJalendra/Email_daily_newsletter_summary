## Summary

Leanstral is Mistral's July 2026 open-source 119B-parameter theorem-proving and code-verification agent, positioned as a *pre-ship verification layer* rather than a code-authoring flagship. Built on Mistral's general-purpose coding framework, Leanstral 1.5 targets formal verification and math-heavy processes: it can *verify proofs, test logic, and catch errors before software ships*. Same-cycle AlphaSignal coverage anchors the math-reasoning capability with a concrete benchmark — *587 out of 672 Putnam problems (~87.4%) at significantly lower cost* than closed-weight competitors — placing Leanstral in the upper tier of math-reasoning agents alongside DeepSeek-Math-V2 and Harmonic's Aristotle Lean-verified pipeline.

The verification-agent positioning is structurally distinct from Claude Code / Cursor Composer / Codex — those systems *write* code, while Leanstral *checks* it. In the emerging [[software-factories]] arc (triage → spec → implement → **review/verify** → ship → monitor), Leanstral sits at the review/verify step, which has previously been dominated by classical static-analysis (SAST) tools and human-reviewer plus LLM-critic layered stacks. As an open-weight 119B model with a formal-verification bent, Leanstral becomes a candidate substrate for the *automated review gate* in [[software-factories]] main loops and pairs cycle-structurally with the [[recursive-self-improvement]] harness-verification substrate (Self-Harness's proposal-validation stage; HarnessX's verification pipeline component).
