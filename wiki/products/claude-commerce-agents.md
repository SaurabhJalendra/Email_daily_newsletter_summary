## Summary

Claude Commerce Agents is [[anthropic]]'s open-source suite of AI shopping-and-merchant assistants shipped under Apache 2.0 on September 3, 2026. The suite ships with two canonical roles — a **shopping agent** (buy-side, guides shoppers through discovery + comparison + checkout) and a **merchant agent** (sell-side, helps store operators configure merchandising + promotions + support) — that plug into any store front-end and run on Claude models. Anthropic reports that stores using the agents see cart sizes increase by up to 35% and shoppers become 60% more likely to complete a purchase.

The release ships with **four vertical demos** — retail, travel, telecom, and ticketing — that give operators a runnable starting point per industry, plus a **[[claude-code]] plugin** that lets developers install the agents into their local coding environment. Combined with the same-week [[claude-fable-5-1]] launch and Anthropic's earlier Agent Skills open standard, Commerce Agents canonicalize Anthropic's mid-2026 shift toward permissive open-substrate distribution for vertical agent-workloads that had previously been closed-tier.
