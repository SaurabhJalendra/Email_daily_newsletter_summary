## Summary

Jev is a Sep 2026 decision-making AI model launched by **Diogo Almeida**, a co-creator/co-inventor of [[chatgpt]] who left [[openai]] to build it. Structurally distinct from generative LLMs, Jev is designed to **live inside software and make judgment calls** rather than produce prose. It returns **typed decisions with confidence scores** — no free-text output, no hallucination surface — targeting the background decision-making work that chatbots aren't the right tool for (routing, ranking, gating, classification, policy calls).

Cost/speed framing anchors Jev as a **~400× cheaper and significantly faster alternative** to [[chatgpt]] and [[claude-opus-5]] for high-volume automation. Positioned as *"AI that can't hallucinate"* — a canonical mid-Sep-2026 counter-frame to the generative-LLM-tier substrate, aimed at production-tier decision loops where cost, latency, and correctness bounds all bind at once.

## Key Facts

- **Vendor**: TypeSafe AI (Diogo Almeida, ex-[[openai]], co-creator/co-inventor of [[chatgpt]])
- **Model class**: "System One Model" — decision model with typed decisions + confidence scores, no free-text generation
- **Training algorithm**: RLCD (novel — Almeida-authored)
- **Architecture framing**: outputs a probability distribution over a *predefined answer space* rather than free-form tokens
- **Cost/speed**: ~400× cheaper + ~200× faster than [[chatgpt]] and [[claude-opus-5]] for equivalent decision workloads
- **Design goal**: background decision-making inside software (routing, ranking, gating, classification, policy calls)
- **Hallucination surface**: none — model cannot generate text at all
- **Target market**: high-volume automation where LLM cost/latency is prohibitive
- **Landing page**: typesafe.ai/blog/introducing-system-one-models-and-jev
- **Pricing**: $0.042 per million input tokens; output tokens free (canonicalized 2026-09-21-morning via The AI Corner)
- **Adoption velocity (Vercel AI Gateway, first day)**: 13% of teams — 2× GPT-5.6 family + 6× Fable 5.1 — "adopted faster than any other model in AI Gateway history"
- **Launch-video views**: 36M
- **Training data**: 100% synthetic (Almeida-attributed)
- **Named open clones (within 48 hours of launch)**: Laya (421M ModernBERT-based) + DiffusionGemmaJev (Google DiffusionGemma-based) + Bespoke Nimble (LoRA-Qwen3.5-9B, ~90% vs Jev ~93%) + SemIf (fka OpenJev, browser-based on Qwen/MiniCPM5) + Jevlike + Kev-0.5B (Qwen2.5-0.5B, MacBook-runnable) + Jared Palmer's 0.5B open-source decision model (MacBook-runnable)
- **Proposed evaluation harness**: CUA-Bench (real-time keyboard/mouse-use decision tasks)
- **Named primitives (2026-09-22-morning canonical triple)**: **Choice** (pick one option) + **Score** (place something on an ordered scale) + **Noul** (answer a yes/no question as a probability)
- **SDK install command**: `npm install @typesafe-ai/sdk`
- **Capability demos**: playing Doom + racing across Wikipedia by choosing between hundreds of links
- **Community projects (2026-09-22-morning triple)**: support-ticket router + browser-agent guardrail + semantic observability tool for agents
- **Application domains**: agent routing + semantic database fields + coding-agent tool routing
- **Cross-vendor integration**: Vercel json-render + Jev experiment renders full UI components from JSON in milliseconds
