## Summary

Vercel eve is [[vercel]]'s open-source agent framework introduced in June 2026 and explicitly framed as "production infrastructure for AI agents." It bundles the production-grade concerns developers typically build themselves — **durable execution, sandboxed compute, approvals, subagents, and evaluations** — into a single framework so teams can ship agents without re-implementing the surrounding machinery. Cycle-2 recoverage (The Art of Saience, 2026-07-05-evening) sharpens the architectural framing into *file-first* — agent capabilities live as filesystem-inspectable artifacts developers can grep, diff, and edit with standard tooling rather than runtime-only state. This positions Vercel eve on the same design-philosophy axis as [[claude-code]] + [[claude-skills]] against the older opaque-runtime agent frameworks.
