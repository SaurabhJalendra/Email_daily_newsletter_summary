## Summary

Muse Wonder is [[meta]]'s Oct 12 2026 frontier model from Meta Superintelligence Labs — the standard tier of the two-SKU Muse Wonder family (alongside the higher-capability [[muse-wonder-full]]). Positioned for **complex software engineering, long-running agentic tasks, advanced computer use, and multimodal long-context reasoning**, Muse Wonder can plan work, delegate to sub-agents, call tools in parallel, verify changes across repositories, and recover from errors across multistep workflows. Context window extends to **1,048,576 tokens** with text + image + video + audio + PDF inputs.

Distribution is **dual-surface**: available through both the Meta Model API (OpenAI-compatible format) and [[muse-code]], at **$4 per million input tokens and $20 per million output tokens**. The release graduates MSL from a 14-month build-up into a canonical frontier-lab tier, positioning Meta directly against OpenAI, Anthropic, and Google on coding agents and long-horizon software-engineering workflows.
