## Summary

Agent Skills is an [[anthropic]]-led open standard for packaging reusable agent capabilities so that multiple agent runtimes can discover, invoke, and compose them without vendor-specific glue. Agent Skills emerged as an extension of Anthropic's internal [[claude-skills]] concept, and in December 2025 was framed as an open-standard publication — positioning it alongside [[model-context-protocol]] as part of the broader ecosystem layer of open agent interoperability, with the [[agentic-ai-foundation]] as the natural stewardship home.
