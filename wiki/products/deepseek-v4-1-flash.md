## Summary

**DeepSeek V4.1-Flash** is DeepSeek's September 2026 efficient open-weight model — a sparse-activation MoE with **~552B total parameters** but only **8-16B active at a time**, delivering frontier-comparable performance at radically lower cost. Reports frame it as **~33× cheaper than [[openai-astra]]** (GPT-6) while outperforming [[claude-opus-5]] and [[gpt-5-6]] Sol on several agentic, coding, and cyber benchmarks. Multimodal (image understanding built-in per Vaibhav Sisinty coverage) and priced aggressively.

## Key Facts

- Vendor: [[deepseek]]
- Architecture: asymmetric CED (Causal Encoder-Decoder) MoE — 552B total parameters, 20-layer causal encoder + 20-layer decoder; 8B active on input / 16B active on output
- Attention/cache architecture: **CSA2 (Compressed Sparse Attention 2)** cross-layer cache-state + retrieval-results sharing + **hierarchical sparse indexing** bounds cost of finding relevant historical tokens + **FP4 (4-bit) KV caching** compresses main KV cache
- KV cache footprint: **~890 bytes per token globally** (~1/4 of V4-Flash, >400× smaller than V1); persistent KV cache on SSD/host memory ~1/8 of V4-Flash — supports 4-8× more concurrent sessions in same KV budget
- Infrastructure efficiency: 4× lower memory-cache needs + 8× lower storage vs previous V4-Pro
- Cost: ~33× cheaper than GPT-6 Astra; ~98% of Astra score at 1.4% of cost; off-peak pricing 50% cheaper
- API model name: `deepseek-flash`
- Modalities: text + image understanding built-in (native multimodal)
- Positioning: open-weight, extreme-price-point efficient successor to [[deepseek-v4]] — Pro-tier retired
- Benchmarks: **AAII 40** (just behind Gemini 3.8 Flash High at 41, at 1/4 the cost per task); outperforms [[claude-opus-5]] + [[gpt-5-6]] Sol on some agentic/coding/cyber benchmarks; beats own V4-Pro on every metric
