## Summary

Core is [[ghost]]'s $3,499 screenless personal computer, designed to run AI agents locally rather than function as a conventional desktop. The hardware pairs an NVIDIA RTX Pro 4000 SFF Blackwell GPU (24GB GDDR7, 8,960 CUDA cores, 770 AI TOPS at 70W) with an AMD Ryzen 5 7600 CPU, 64GB of system RAM, and a 1TB SSD. Users control it through a phone app, with optional voice interaction; preinstalled models reportedly include Qwen-3.8-Next, Qwen-3.8-27B, and Gemma-4-31B. The company says personal data and model activity remain encrypted and on-device, positioning Core as a private "brain in a box" for continuously running agents.

Core matters as a market signal rather than for its individual specs: it packages workstation-class GPU memory and AI acceleration into a compact consumer appliance explicitly built for *autonomous personal agents* rather than chat, pairing the hardware substrate with Ghost's phone-app agent harness. Adoption risks include the $3,499 price, the 24GB VRAM ceiling, and the practical reliability + safety of unattended personal agents.
