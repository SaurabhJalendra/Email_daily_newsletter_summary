## Summary

Claude Code Agent View is a unified dashboard for managing every active Claude Code session in one place — research preview launched 2026-05-12 for Pro, Max, Team, Enterprise, and API plans. Surfaces session status (finished / running / waiting for input), supports reordering and pinning, lets users supervise multiple parallel agents from a single terminal tab, and integrates background tasks. Positioned as the multi-session-aware operations layer above Claude Code — turning it from a single-session coding agent into a "task-manager for many coding agents at once." Pairs with the [[claude-code]] `/goal` and `/loop` command additions (2026-05-14) and the `/grok-build`-style multi-agent CLI direction the wider field is moving in.
