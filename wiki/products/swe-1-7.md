## Summary

SWE-1.7 is [[cognition]]'s July 2026 near-frontier coding model, launched as a cheap coding-agent-tier alternative to closed frontier flagships at **$1.97 per task**. Structurally novel because it's *built on top of China's open-source Kimi K2.7* ([[moonshot-ai]]) as the base substrate, then improved using reinforcement learning + Cognition's RL-pipeline enhancements (better infrastructure + more stable training + new long-horizon-task techniques). The model is available in Cognition's Devin agent via web, desktop, and CLI surfaces, and is positioned as capable of tackling *"longer, real-world coding tasks"* rather than short SWE-bench-tier snippets.

Structurally, SWE-1.7 marks the first publicly framed instance in this wiki of a *US frontier-lab-tier coding-agent-vendor productizing a Chinese-open-source model as substrate for its own brand*. Cognition joins the *use-open-source-Chinese-model-as-inference-substrate* mid-2026 cohort ([[ollama]] US-hosted [[glm-5-2]] + [[baseten]] hosted [[kimi-k2-7-code]] + [[friendliai]] Frontier-Inference-Cloud open-model tier) — extending the *US-vendor-productizes-Chinese-open-source* pattern from cloud-inference-tier into *US-vendor-fine-tunes-own-brand-on-Chinese-open-substrate* tier. The $1.97/task cost anchor pairs cycle-structurally with the [[grok-4-5]] $2.49/task Claude-Code cost anchor + [[gpt-5-6]] Terra $2.50/$15 cost-optimized-daily-driver + [[claude-fable-5]] Advisor 92%/63% + Orchestrator 96%/46% patterns as the mid-2026 canonical *"near-frontier at lower cost"* positioning across multiple vendors.
