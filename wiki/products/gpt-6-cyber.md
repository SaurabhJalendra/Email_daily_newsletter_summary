## Summary

GPT-6-Cyber is [[openai]]'s Nov 2026 GPT-6-tier cybersecurity specialist — the successor to [[gpt-5-6-cyber]] in OpenAI's Daybreak cyber-model line — trained to find and validate exploitable vulnerabilities while staying within scope set by researchers. Access is limited to select Daybreak Red customers via API and Codex. Vendor-reported benchmarks place it at **48.5% on ExploitGym** (up from GPT-5.6-Cyber's 32.1%) and **95% of RemoteExploitBench tasks completed**.

OpenAI pairs the model release with the public disclosure of an **autonomous Linux-kernel pipeline** that used GPT-6-Cyber to find **81 high-severity Firefox vulnerabilities**, extending the multi-cycle [[openai-daybreak]] + [[patch-the-planet]] AI-assisted-vulnerability-discovery arc from *OSS-coordinated-disclosure-tier* into *OS + browser-kernel-level autonomous-discovery-tier*.
