## Summary

Open Lovable is an open-source clone of the [[lovable]] AI app-builder, released by the [[firecrawl]] team in mid-September 2026. The repository has 28,000+ GitHub stars at launch and reproduces Lovable's prompt-to-full-stack-web-app workflow as a self-hostable reference architecture. It requires API keys from [[firecrawl]], a model provider ([[gemini]], [[anthropic]], [[openai]], or [[groq]]), and a Vercel-hosted sandbox to run locally.

As a reference architecture, Open Lovable ships the code but explicitly not the productization — turning it into a business requires the operator to add authentication (e.g., Supabase or Clerk), billing (e.g., Stripe), usage caps, and a marketable business idea. This positions Open Lovable as a *reproducible substrate for building vibe-coding-style products* rather than a Lovable-competitor SaaS. It lands the same cycle as Lovable's own $400M/$13.3B ratchet ([[lovable]] 2026-08-13-evening) — a reference architecture surfacing at the moment Lovable's commercial success validates the category.
