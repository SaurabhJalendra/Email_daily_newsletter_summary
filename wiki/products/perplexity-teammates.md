## Summary

**Perplexity Teammates** is Perplexity's early-November-2026 workplace AI-agent product that productizes "always-on" persistent agents performing continuous research and operational tasks for enterprise users. It extends the multi-cycle Perplexity agent-substrate arc — which previously spanned [[perplexity-brain]] memory, [[perplexity-computer]] 19-model orchestration, consumer-and-enterprise distribution variants like [[perplexity-personal-computer]] and [[perplexity-portable-computer]], and open-sourced runtimes like SPACE — into a *persistent, workplace-anchored agent tier* where the agent does not wait for a prompt but runs on a schedule or trigger.

Teammates sits structurally alongside [[claude-managed-agents]] + [[claude-dreams]] idle-period memory consolidation, Mistral Studio managed agents, and Cognition's always-on Devin agent as canonical early-Nov-2026 productizations of the chat-based-assistant → persistent-agent substrate-shift. The pattern creates new AgentOps-tier concerns: task orchestration, permissions, monitoring, cost controls, and reliability — practitioner-impact-scope that moves agent operations from an experimental surface to a production one.
