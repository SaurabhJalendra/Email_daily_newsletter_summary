## Summary

Microsoft Scout is Microsoft's first always-on "Autopilot" agent, unveiled at Build 2026. It is positioned as an executive-assistant agent that coordinates work across email, calendar, and documents in the background rather than waiting for user prompts — Microsoft's answer to [[claude-managed-agents]] and OpenAI's Codex Sites surface. Scout is initially gated behind a GitHub Copilot subscription with usage-based pricing layered on top, marking Microsoft's first "agent SKU" with metered consumption rather than seat-based access. The framing positions Windows + Microsoft 365 + Azure Foundry as a coordinated agent control plane, with Scout as the user-facing always-on layer and [[mai-thinking-1]] family models doing the reasoning work.
