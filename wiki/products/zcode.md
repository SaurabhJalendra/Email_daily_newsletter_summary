## Summary

ZCode is [[zhipu-ai]]'s cross-platform (macOS + Windows + Linux) AI coding IDE surfaced in the 2026-07-03 morning cycle via TLDR AI. It combines AI agents with existing developer tools to let developers *plan, code, review, and deploy without friction* — the coding IDE productization of Zhipu's [[glm-5-2]] frontier-coding model, with a variant of GLM-5.2 tuned specifically for ZCode as the underlying agentic-coding engine.
