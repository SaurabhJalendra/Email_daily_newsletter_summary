## Summary

Kimi Work is [[moonshot-ai]]'s desktop agent product — a Windows/macOS assistant that connects to local files, drives a browser autonomously, and chains multi-step web workflows. Positioned as a 24/7 automation surface, it extends Moonshot's stack beyond model APIs and the [[kimi-code-cli]] coding-CLI tier into the *general-purpose desktop agent* competitive surface currently occupied by [[chatgpt-work]] (OpenAI), [[claude-cowork]] (Anthropic), and the [[cursor]] general-agent expansion.

The launch pairs cycle-structurally with the mid-July 2026 [[kimi-k3]] release and Moonshot's rapid product-line broadening — Kimi K3 (foundation model) + Kimi Code CLI (coding-agent CLI) + Kimi Work (desktop agent) constitutes Moonshot's first publicly framed *three-tier vertical productization* in this wiki, matching the depth of Western frontier-lab consumer surfaces.
