## Summary

Claude Platform on AWS gives Anthropic an AWS-native enterprise distribution path: customers access the same APIs, features, and console experience available directly through Anthropic — including [[claude-managed-agents]], code execution, files, MCP connectors, and experimental features — but run through their existing AWS account with AWS IAM authentication and CloudTrail auditing. Launched 2026-05-12. The move closes a gap with [[microsoft]] Foundry (Claude inside Azure) and [[google]] Cloud (TPU-hosted Claude) by making AWS the third hyperscaler with native Anthropic platform parity, eliminating the need for a separate Anthropic account for AWS-resident workloads.
