## Summary

ChatGPT Work is OpenAI's new agentic workspace inside ChatGPT, launched simultaneously with the [[gpt-5-6]] GA on 2026-07-09/10. It is designed to tackle complex, long-running projects by orchestrating work across a user's apps, data, and tools — the user provides an *outcome* rather than a prompt, and Work gathers context, breaks the job into steps, executes for hours, and hands back finished materials (documents, spreadsheets, presentations, web apps). Powered by the GPT-5.6 Sol/Terra/Luna family, it is positioned as OpenAI's direct competitive answer to Anthropic's [[claude-cowork]] and is available across ChatGPT Pro, Enterprise, Edu, Plus, and Business plans, accessible in the ChatGPT desktop app even for Free users.

The launch coincides with OpenAI merging ChatGPT and Codex into a single new desktop app that puts Chat, Work, and Codex together on every plan (the old desktop app becomes ChatGPT Classic and the standalone Atlas browser is being sunset). TAAFT frames Work as the app that *"turns scattered files into finished documents, sheets, and slides"*, with TLDR + Rundown AI + Evolving AI Insights + World of AI all landing HIGH-priority coverage in the same cycle.

## Key Facts

- Vendor: [[openai]]
- Underlying model substrate: [[gpt-5-6]] family (Sol / Terra / Luna)
- Underlying runtime substrate: **Codex harness** — inherits Codex's models, sub-agents, and browser-use capabilities
- Browser runtime: **managed Chrome service** inside a cloud computer
- Workspace primitive: **persistent workspace with working-directory-per-task** (agent can create files/folders/install dependencies; limited sovereignty over the computer)
- Engines: **proactive-suggestions engine** + **scheduling system** + **browser timeline feature** (view/interact with agent's past actions)
- Storage: **library** for user files + artifacts
- Plugins: **operational + role-specific + service** three-type taxonomy; **1,000+ plugin directory** (discovery/recommendation still weak)
- Interaction model: *outcome-based* (user provides target artifact + goal; Work owns decomposition + execution)
- Runtime: hours-long autonomous execution across apps, data, and tools
- Output artifacts: documents, spreadsheets, presentations, web apps
- Distribution: ChatGPT Pro, Enterprise, Edu, Plus, Business; free-tier access via desktop app
- Delivery surface: web + mobile + desktop (feature-parity varies); unified ChatGPT + Codex desktop app (replaces standalone ChatGPT Classic); Atlas browser sunset
- Roadmap: **plans to merge with the main ChatGPT product by end of 2026**
- Competitive positioning: direct answer to [[claude-cowork]]
