## Summary

OpenRouter is a **multi-model inference marketplace and routing platform** — a canonical model-aggregator for LLM-app developers, providing a unified API surface across frontier + open-weights vendors, community-spend-weighted routing, and cross-vendor benchmark leaderboards. Its Aug 2026 monthly-recap product-motion cycle ships **five new leaderboards** (BrowseComp, HLE, DeepSearchQA, WideSearch, GPQA Diamond — four of which hold the model fixed and vary the search setup instead), **Auto Router (Beta)** which classifies each request into one of thirty task types and routes it to the models the OpenRouter community is actually spending on over the trailing seven days, **Ori Eval** CLI benchmarking tool for own-your-work evaluation with an LLM judge, a **Batch API** at typically half of standard per-token pricing, and **Classifiers** for per-generation workspace tagging + spend attribution.

Product-motion also includes new-model onboarding across seven concrete anchors — **Tencent HY3, Moonshot Kimi K3, Grok 4.5, GPT-5.6, Claude Opus 5, Google Gemini 3.6 Flash, and Gemini 3.5 Flash Lite** — plus US in-region Amazon Bedrock inference for certain models, the Responses API leaving beta (validates DeepSeek V4's triple-format-interop pattern at marketplace-tier), and automatic SDK release cadence for Python + TypeScript + Go keeping pace with the API. Positions OpenRouter as canonical *multi-vendor frontier-aggregation + wire-format-interop-across-vendors marketplace-tier substrate* alongside [[nebius]] Token Factory + [[fireworks]] frontier-open-weight-hosting + [[together-ai]] open-source-plumbing.
