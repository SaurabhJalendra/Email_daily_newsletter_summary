## Summary

Auth0 is an identity and authentication platform (part of Okta). In early October 2025 it launched "Auth0 for AI Agents" — a developer preview positioned as the first comprehensive authentication solution for AI agents and GenAI apps, covering token vaults, fine-grained authorization for RAG, user auth for chatbots and background workers, and async authorization for autonomous agents.

## Key Facts

- Features at launch: Token Vault (API keys for Google, GitHub, etc.), Fine-Grained Authorization for RAG, user auth for chatbots and background workers, async authorization for autonomous agents
