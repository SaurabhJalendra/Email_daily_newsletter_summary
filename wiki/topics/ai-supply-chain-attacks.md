## Summary

AI supply-chain attacks target the developer-package ecosystems (npm, PyPI, Packagist, IDE marketplaces) that underpin AI toolchains. Since May 2026, coverage has centered on **DPRK-affiliated campaigns** (Mini Shai-Hulud, Glassworm, JetBrains Marketplace, PolinRider Packagist) that compromise open-source packages to reach downstream developers and AI-tool users. The August 2026 Axios / Chalk / Debug / typo-crypto npm compromises escalate the target profile from *opportunistic packages* into *foundational dependencies used by virtually every JavaScript project* — including AI SDKs and agent frameworks — dramatically expanding blast radius. Defensive responses have emerged at the **registry tier** (Github Dependabot's 3-day hold-and-observe delay on version-update PRs) and at the **coalition tier** ([[akrites]] Linux Foundation + tech-giants initiative). The attack surface is structurally distinct from [[prompt-injection]] (input-tier attacks on running models) and from AI-generated-exploit-code arcs ([[ai-cybersecurity-arms-race]]): it targets the *developer clone-and-run workflow* before the AI system is ever invoked.

## Key Facts

- Ecosystems targeted (through 2026-08): npm, PyPI, Packagist, JetBrains Marketplace, GitHub
- New target class (Aug 2026): **AI-provider-key middleware libraries** (LiteLLM) — expands attack-surface into the *AI-adjacent-middleware tier* distinct from AI-coding-assistants
- Attacker cohort: DPRK-affiliated state-linked hacking units (per Anthropic 2026-06-22 letter-to-Congress + Sysdig JADEPUFFER research); Aug 2026 400+ npm compromise attribution TBD
- Attack vectors: package compromise (malicious releases), maintainer social engineering, marketplace-extension injection, deceptive setup-instructions (with [[claude-code]] indirect-prompt-injection), **self-propagating worm-via-stolen-publishing-access** (Aug 2026)
- Concrete blast-radius (Aug 2026 LiteLLM): 2,500+ organizations + 430,000+ CI/CD pipelines
- Credential-target class (Aug 2026): AI-provider-key + SSH-key + cloud-credential + token quadruple-target
- Defensive responses: Github Dependabot 3-day hold-and-observe (Aug 2026), [[akrites]] Linux Foundation coalition (Jul 2026), Sysdig runtime-detection (containers), Socket Firewall IDE-tier inline scanning ([[replit]], Aug 2026)
- Downstream AI-tooling impact: Axios/Chalk/Debug sit transitively in nearly every JS-based AI SDK, agent framework, dashboard; LiteLLM sits at the *AI-provider-key middleware layer* used by Python AI-app developers
