## Summary

Reasoning Trace Extraction is a class of API vulnerabilities disclosed by Alexander Panfilov et al. on 2026-08-11 that enables extraction of the *hidden reasoning tokens* (chain-of-thought planning tokens) generated by frontier LLMs before they emit user-visible output. The technique reportedly affects every frontier AI company's API (Claude, GPT, Gemini), with the extracted reasoning-token count matching the billed API thinking-token count 1:1 for most prompts queried. Extracted reasoning can be decoded and ported to different models, sessions, or users, and used to improve open models — making the vulnerability a canonical *distillation-attack substrate* for the mid-2026 open-vs-closed competitive tier. Matthew Green coordinated responsible disclosure to vendors.
