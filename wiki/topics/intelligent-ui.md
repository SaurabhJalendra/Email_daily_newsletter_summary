## Summary

Intelligent UI is [[openai]]'s October 2026 ChatGPT UX capability, launched with the global GPT-6 rollout. Instead of returning only text, Intelligent UI lets ChatGPT dynamically compose responses from **text, visuals, diagrams, charts, graphics, forms, tappable buttons, calculators, bill splitters, games, and other interactive tools** that users operate directly inside the conversation. ChatGPT can still fall back to a conventional text answer when more appropriate. GPT-6 can also begin responding while continuing to reason or use tools — a *partial-results-while-reasoning* UX primitive.

The feature matters because it reframes the chat window as a *programmable application surface* rather than a text channel. Rolled out globally to 1.2B+ weekly ChatGPT users — initially to Plus/Pro/Business/Enterprise with GPT-6 Sol, then to Free/Go with GPT-6 Luna. GPT-6 Astra, the higher-end reasoning tier, does **not** support Intelligent UI in ChatGPT.

Intelligent UI pairs cycle-structurally with [[solaris]] (Runway's Sep 2026 "Interface World Model" generating full UIs frame-by-frame) and [[gemini-omni]] (Google's any-input → editable video model) as *canonical late-2026 three-vendor interactive-generated-interface substrate cluster*. It is likely to compound competitive pressure on Gemini, Claude, Muse, and Grok to produce dynamically-generated UIs rather than text-only answers.
