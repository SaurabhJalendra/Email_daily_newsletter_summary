## Summary

AI browsers are a product category where the browser itself acts as an AI runtime — remembering context across sessions, automating routine tasks, and exposing agentic search. In early October 2025 the two reference products were [[opera-neon]] and [[perplexity-comet]], both positioned as direct competitors to Microsoft's Copilot-in-Edge and Google's Chrome AI features. The category became a frontier-lab race on 2025-10-22 when [[openai]] launched [[chatgpt-atlas]] — a Chromium-based browser with ChatGPT built in — which immediately attracted a hidden-text [[prompt-injection]] disclosure (Oct 23) that became the first big public security event for the category. [[chatgpt-atlas]] picked up an Agent Mode in early November.

## Key Facts

- Reference products: [[opera-neon]], [[perplexity-comet]], [[chatgpt-atlas]] (Oct 2025), Microsoft AI browser (Oct 2025)
- Monetization patterns: subscription (Opera Neon), bundled with assistant subscription (Atlas, Comet)
- Positioning overlaps with [[computer-use]]: browser = a constrained OS for agents
- Security category: hidden-text and visual [[prompt-injection]] are the dominant attack class

## Open Questions

- Can an AI browser survive as a standalone product vs AI features baked into Chrome/Edge?
- Privacy model: what does persistent browsing memory mean for data custody?
- Does Atlas's hidden-text vulnerability force a category-wide content-security model (signed DOM, sandboxed prompts)?
